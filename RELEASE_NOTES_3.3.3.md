# FluentBird Polished 3.3.3

This is a major visual and quality-of-life overhaul of the original Thunderbird Outlook Theme.

## Highlights

- Reworked Outlook-style message cards with improved spacing, selection, unread states, and properly aligned row controls.
- Combined sender avatars and quick delete into one add-on while preserving Thunderbird's favourite star.
- Added a one-click Email Accounts switcher that opens All Mail or Inbox without expanding or scrolling All Folders.
- Added provider groups, custom headers, optional flat mode, drag-and-drop ordering, hidden accounts, adjustable density, and live unread badges.
- Added options to hide All Folders and the account-switcher header buttons.
- Automatically opens date groups and preserves the message-list scroll position when selecting mail.
- Fixed duplicated account shortcuts, stale selection highlights, attachment/control overlap, observer-related freezes, and unreliable cold-start initialization.
- Refined the folder pane, tabs, reading pane, light/dark styling, narrow-window behaviour, keyboard focus, and reduced-motion support.

## Compatibility

Designed for Thunderbird 140 and newer using Card View.

## Upgrading from 1.0

Back up and replace your existing `chrome` folder, disable or remove the old Sender Avatars and Trash Button add-ons, then install the included `polished-ui.xpi` through **Add-ons and Themes → Extensions → gear menu → Install Add-on From File…**.

The original [v1.0 release](https://github.com/Browmew/thunderbird-outlook-theme/releases/tag/v1.0) remains available with the original theme and separate add-ons.

See the repository README for complete installation and usage instructions.
